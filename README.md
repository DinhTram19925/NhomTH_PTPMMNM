## Hướng dẫn chạy trên XAMPP
1. Clone dự án vào thư mục htdocs của XAMPP.
2. Mở http://localhost/phpmyadmin, chọn tab SQL và chạy toàn bộ nội dung file database/royaldine_5s.sql.
3. Truy cập: http://localhost/NhomTH_PTPMMNM/
